# Sân Nhà — Pressure Garden

Game rửa sân 3D với ba công việc, hai đầu phun, cây cần bảo vệ, đồng hồ, tiền thưởng và nâng cấp được lưu bằng localStorage. Mô hình và bối cảnh được dựng riêng bằng hình học 3D. Dùng Three.js (MIT), bản đi kèm để không cần tải thư viện khi chơi.

Mở trực tiếp `play.html` để chơi, không cần máy chủ. Hoặc chạy: `node serve.cjs`, sau đó mở http://localhost:3000.

WASD / phím mũi tên: di chuyển. Giữ chuột: phun. Q hoặc 1/2: đổi đầu phun. Escape: tạm dừng. Trên điện thoại: chạm sân để phun, dùng các nút mũi tên để di chuyển. Phun xòe làm sạch rộng; tia mạnh xử lý vết dầu từ công việc 2. Hoàn thành ít nhất 97.5% để qua màn. Nâng cấp bằng tiền kiếm được.

Tiến độ tiền và nâng cấp lưu trong trình duyệt. Âm thanh tổng hợp bằng Web Audio. Font có thể tải Google Fonts; có font hệ thống dự phòng.
